## 1. 설명의 중심

### 한 문장 정의

실험플랫폼은 새 기능을 일부 사용자에게 먼저 보여주고, 누가 어떤 경험을 했으며 이후 어떤 행동을 했는지 기록해 결과를 비교할 수 있게 하는 시스템입니다.

### 핵심 차별점

“사용자를 두 그룹으로 나누는 것”보다 **“노출과 결과 행동을 같은 실험 안에서 연결하는 것”**이 중요합니다.

- Feature Flag로 코드 배포와 기능 노출 시점을 분리합니다.
- 같은 사용자는 같은 조건에서 일관된 버전을 받습니다.
- SDK나 API가 사용자별 버전을 결정하고 노출 기록을 남깁니다.
- 개발자는 클릭·가입·신청 같은 목표 행동을 `track()`으로 기록합니다.
- 플랫폼은 버전별 노출 수, 전환율, SRM 경고와 통계 결과를 함께 보여줍니다.

따라서 이 서비스는 단순한 “기능 켜기/끄기 도구”보다 **새 기능의 효과를 실제 사용자 행동으로 확인하는 개발·의사결정 환경**으로 설명합니다.

## 2. 30초 소개

### 30초 버전

실험플랫폼은 새로운 화면이나 기능을 모든 사용자에게 바로 공개하지 않고 일부 사용자에게 먼저 보여준 뒤 결과를 비교할 수 있게 합니다. 운영자는 웹에서 실험 대상과 성공 기준을 설정하고, 개발자는 SDK나 API로 사용자별 버전을 요청해 기존 화면과 새 화면을 나눠 보여줍니다. 플랫폼은 누가 어떤 버전을 봤는지 기록하고, 클릭이나 신청 같은 목표 행동을 함께 수집해 버전별 전환율과 통계 결과를 보여줍니다. 이를 바탕으로 새 기능을 전체 적용할지, 더 지켜볼지, 중단할지 판단할 수 있습니다.

### 더 짧게 · 10초 버전

새 기능을 일부 사용자에게 먼저 보여주고, 노출과 행동을 연결해 효과를 비교할 수 있게 하는 실험 개발 플랫폼입니다.

## 3. 아키텍처 흐름

```text
운영자
  │ 실험 · 성공 기준 · 대상 설정
  ▼
실험플랫폼 관리 화면
  │
  ▼
실험플랫폼 API ◀──── ExperiBase SDK ◀──── 연동 서비스 코드
  │ 사용자별 버전 결정                  │
  ▼                                     ▼
control / treatment 반환          화면 또는 기능 렌더링
  │                                     │
  └──────── 노출 기록 ──────────────────┤
                                        │ 클릭 · 가입 · 신청
                                        ▼
                               행동 이벤트 track()
                                        │
                                        ▼
                               버전별 결과 비교
                                        │
                                        ▼
                         전체 적용 · 유지 · 중단 · 재실험
```

설정 → 경험 결정 → 화면 제공 → 노출·행동 기록 → 결과 비교 → 적용 또는 중단 결정으로 이어지는 전체 흐름입니다.

### 각 구성요소를 한마디로

| 구성요소 | 역할 | 부스용 표현 |
|---|---|---|
| Experiment | 가설·기간·성공 기준·비교 버전 관리 | “무엇을 왜 비교할지 정한 실험 계획입니다.” |
| Feature Flag | 사용자별 기능 노출 제어 | “코드 배포와 기능 공개를 분리하는 스위치입니다.” |
| Segment | 실험 대상 사용자 그룹 | “누구에게 실험할지 정한 대상 명단입니다.” |
| SDK·API | 사용자별 버전 결정 요청 | “서비스가 이 사용자에게 무엇을 보여줄지 묻는 연결점입니다.” |
| Exposure | 누가 어떤 버전을 봤는지 기록 | “결과 비교의 기준이 되는 노출 기록입니다.” |
| Track Event | 클릭·가입·신청 같은 결과 행동 | “사용자가 실제로 무엇을 했는지 남깁니다.” |
| Result | 전환율·SRM·통계 결과 | “새 기능을 적용할지 판단할 근거입니다.” |
