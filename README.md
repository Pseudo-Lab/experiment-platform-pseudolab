# 데이터 이니셔티브 활동 페이지

Status: active
Last-Validated: 2026-11-13

Data Initiative의 목적, 주요 활동, 함께하는 사람들, 프로젝트와 기록을 소개합니다.
Iterglow(이터글로)는 활동을 지원하는 대표 프로젝트이며, GitHub·팀 블로그·소식 신청으로 연결합니다.
Iterglow는 팀이 개발하는 오픈소스 A/B 테스트·실험 플랫폼입니다.
한국어와 영어를 함께 제공합니다.
다크모드는 기기 설정을 따르며, 상단 해·달 버튼으로 직접 선택한 모드는 다음 방문에도 유지됩니다.

- 공개 주소: https://pseudo-lab.github.io/experiment-platform-pseudolab/
- 홈페이지 소스 및 배포: 이 레포의 `pages` 브랜치
- 실제 서비스 코드: `main` 브랜치

## 개발 및 배포

Node.js 22에서 실행합니다.

```sh
npm ci
npm run dev
npm run build
npm run preview
```

문서만 바꾼 경우를 제외하고 `pages` 브랜치에 push하면 `.github/workflows/pages.yml`이 `dist/`를
GitHub Pages로 배포합니다. Pages의 게시 방식은 GitHub Actions이며,
`github-pages` 환경은 `pages` 브랜치 배포만 허용합니다.
서비스의 Docker·GitOps workflow는 이 브랜치에 포함하지 않습니다.
이 브랜치는 홈페이지 전용의 독립 이력이며 `main`에 병합하지 않습니다.

## 내용 변경

- 문구·진행 소식·외부 링크: `src/main.jsx`의 `copy`와 `urls`
- 한국어(`ko`)와 영어(`en`)를 함께 수정합니다.
- 팀원 사진·프로필 링크·소개: `src/main.jsx`의 `members` (사진·링크는 공개 프로필 기준, 기여 소개는 총괄 초안을 사용자 확인 후 반영; 자동 동기화 아님)
- 스타일: `src/style.css`
- 기술 글 원문은 팀 블로그에 게시하고 관련 링크로 연결합니다.
- 비밀값·운영 데이터·내부 회의록은 공개하지 않습니다.
- 수도콘 자료의 데이터·실험·운영 설명은 팀 소개와 기여 안내에 재구성합니다. 원본 PDF·PPT·HTML을 홈페이지 저장소에 추가하거나 자료용 브랜치로 연결하지 않습니다.
- 현재 제공하는 기능과 팀의 목표를 구분합니다. 자동 복구·AI 실험 에이전트·공개 실험 데이터셋을 출시된 기능으로 표현하지 않습니다.
- 정식 서비스는 `https://iterglow.pseudolab-devfactory.com`, SDK 가이드는 같은 서비스의 `/docs/sdk`로 연결합니다.

## 이전 및 검증 인계

- 기존 Sites 시안에서 홈페이지 소스만 복사했습니다. Sites 식별자·인증정보·스크린샷·기존 저장소 이력은 포함하지 않았습니다.
- GitHub Pages의 레포 경로에 맞춰 Vite `base`를 설정하고 재현 가능한 설치를 위해 lockfile을 포함합니다.
- 배포 전 clean install·build 및 실제 경로에서 KO/EN·주/보조 버튼·외부 링크·모바일 메뉴·진행 소식·가로 넘침을 검증합니다.

## 페이지 구성과 표현 기준

- 목적 → 주요 활동 → 함께 만드는 사람들 → 프로젝트와 기록 → 소식·참여 관심 순으로 구성합니다.
- 목적은 커뮤니티의 더 나은 의사결정을 돕는 것입니다. 첫 화면의 주 행동은 주요 활동 탐색이며, Iterglow는 보조 링크로 연결합니다.
- 이전 활동 방향 카드와 요약 줄은 주요 활동으로 통합합니다. 기수·완료 사례·다음 계획을 같은 활동 분류로 섞지 않습니다.
- 주요 활동은 실험 플랫폼 구축, 비영리 커뮤니티 데이터 수집·정리, 실험 설계와 분석, 서비스 연동, 기술 조사와 문서화의 다섯 영역입니다. 설명이 항상 보이며 데스크톱은 5개를 한 줄에 모두 표시하고, 태블릿은 3개·2개 두 줄로, 모바일은 다음 카드 일부가 보이는 가로 스크롤로 배치합니다. 직접 스와이프하거나 키보드로 넘길 수 있고, 자동 재생은 하지 않습니다. 각 활동은 의미에 맞는 장식용 아이콘과 은은한 색으로 구분하며, 카드 자체에는 클릭 동작을 부여하지 않습니다.
- 장기적인 데이터 가치평가 표준 비전은 활동 경험을 축적하고 공유하는 과정과 연결해 한 번만 설명합니다.
- 프로젝트와 기록은 Iterglow·GitHub·팀 블로그 세 카드로 통합합니다. Iterglow에는 서비스와 SDK 가이드 링크를 제공하며, 12기 회고 연동은 홈페이지에 별도 사례 카드로 표시하지 않습니다.
- 첫 소개문은 점을 붙인 두 항목을 사용합니다. 본문에는 중복되는 영문 섹션 번호·진행 상태 태그·활동 소제목을 추가하지 않습니다.
- 팀원 정보와 공개 프로필은 유지합니다. 소식받기와 참여 관심은 현재 팀원 모집으로 표현하지 않습니다.
